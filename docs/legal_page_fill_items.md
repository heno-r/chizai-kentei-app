# 固定ページの公開前入力項目

`/terms/`, `/privacy/`, `/legal/` はページ自体は用意できていますが、
正式公開前に次の情報を埋める必要があります。

## 1. 利用規約 `/terms/`

- サービス提供者名
- 規約の施行日
- 規約改定時の告知方法
- アカウント停止や利用制限の条件
- 準拠法、管轄裁判所の扱い

## 2. プライバシーポリシー `/privacy/`

- 運営者名
- 問い合わせ窓口ページ
- 利用する外部サービス名
  - Supabase
  - Stripe
  - Cloudflare
- 保存する学習履歴の範囲
- 開示、訂正、削除の受付方法

## 3. 特定商取引法に基づく表記 `/legal/`

- 販売事業者名
- 所在地
- 問い合わせ先フォームまたは窓口
- 電話番号または代替窓口
- 販売価格の正式表記
- 支払方法
- 提供時期
- 返金、キャンセル条件

## 4. 現時点でほぼ確定してよい項目

- 運営屋号: `しけん準備室`
- サービス名: `しけん準備室 知財3級対策`
- 販売事業者名: `佐々木隆司`
- 商品名: `3級プレミアム版`
- 価格表記: `1,200円`
- 課金方式: `買い切り`
- 補足表記: `追加月額料金なし`
- 提供対象: `知的財産管理技能検定3級`
- 問い合わせ窓口: `/contact/`

## 4.5. 表記の分け方

- サイト上のサービス名は `しけん準備室 知財3級対策` を使う
- 運営名の仮置きは `しけん準備室` を使う
- `/legal/` の販売事業者名は、公開時に本名または正式な商号で記載する
- 必要なら `販売事業者名: 本名（屋号: しけん準備室）` の形にする

## 5. 公開前の最低完了条件

- `/terms/` に施行日が入っている
- `/privacy/` に問い合わせ窓口と外部サービス名が入っている
- `/legal/` に販売者情報、価格、返金条件が入っている
- 3ページとも `雛形` や `公開前` の文言が消えている

## 補足

- 問い合わせ先メールアドレスを公開しない代わりに、`/contact/` の問い合わせフォームを使う
- 通信販売の表示では、氏名、住所、電話番号の扱いに注意する
