# 知財検定学習アプリ プラン設計

## 前提

- プランは `無料版` と `プレミアム版` の2段構成
- 当面の主対象は `3級`
- マネタイズは `無料 + 買い切り`
- 想定価格の初期案は `3級完全版 1,200円`
- 主戦場は `試験1か月前`

## 価値設計

### 無料版

- 役割: `解けることを体験する`
- 訴求: `まずは無料50問でお試し`
- 提供価値:
  - 順番学習
  - ランダム学習
  - 正誤判定
  - 基本解説
  - 簡易的な履歴表示

### プレミアム版

- 役割: `合格効率を上げる`
- 訴求: `全問題 + 苦手復習 + 直前14日モード`
- 提供価値:
  - 3級の全問題
  - カテゴリ別学習
  - 間違えた問題だけ復習
  - 苦手カテゴリ分析
  - 優先復習キュー
  - 今日のおすすめ問題
  - 直前14日モード
  - 試験日までの学習プラン
  - 模試セット
  - 詳細な学習履歴

## 画面ごとのロック方針

### 開始画面

- 無料版で解放:
  - 順番学習
  - ランダム学習
  - 無料問題数の表示
- プレミアム版で解放:
  - カテゴリ別学習
  - 要復習だけ学習
  - 今日のおすすめ問題
  - 直前14日モード
  - 学習プラン
  - カテゴリ別成績
  - 詳細履歴
- 導線:
  - ロック中のモードカードに説明文を表示
  - 下部にプレミアム訴求パネルを表示

### クイズ画面

- 無料版で解放:
  - 回答
  - 正誤判定
  - 基本解説
- プレミアム版で解放:
  - 要復習登録
  - 中断してあとで再開
- 導線:
  - ロック機能を押したときは、プレミアム価値を説明する案内を出す

### 結果画面

- 無料版で解放:
  - 正答率
  - 苦手カテゴリの簡易表示
  - 間違えた問題の一覧表示
- プレミアム版で解放:
  - 間違えた問題だけ復習
  - 苦手カテゴリを続けて学習
  - 要復習だけ解き直す
- 導線:
  - 結果直後にプレミアム訴求パネルを表示
  - `苦手を残さず仕上げる` 文脈で訴求する

## データ設計メモ

- `required_plan` は `free / premium` の2値に寄せる
- 旧 `standard` は互換目的で `premium` と同義に扱う
- `review_tool` と `content_admin` の publish 選択肢も `free / premium` にそろえる
